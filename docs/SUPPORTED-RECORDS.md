# BIFF8 record support matrix

Legend:

- **Read**: parsed and used by the native reader
- **Write**: generated by the native writer
- **Skip**: safely ignored when reading
- **Planned**: not yet emitted or exposed

| Record | ID | Read | Write | Notes |
|---|---:|:---:|:---:|---|
| BOF | `0x0809` | Yes | Yes | Workbook globals and worksheet substreams |
| EOF | `0x000A` | Yes | Yes | Terminates each substream |
| BOUNDSHEET | `0x0085` | Yes | Yes | Sheet name, state, type, and stream offset |
| CODEPAGE | `0x0042` | Yes | Yes | Writer emits Unicode code page 1200 |
| DATEMODE | `0x0022` | Yes | Yes | 1900 and 1904 systems |
| WINDOW1 | `0x003D` | Skip | Yes | Workbook window defaults |
| FONT | `0x0031` | Skip | Yes | Writer currently emits a default font |
| FORMAT | `0x041E` | Yes | No | Custom formats used for date detection |
| XF | `0x00E0` | Yes | Yes | Reader maps number formats; writer emits default/date/date-time XFs |
| STYLE | `0x0293` | Skip | Yes | Writer emits built-in Normal style |
| SST | `0x00FC` | Yes | Yes | Unicode shared strings |
| CONTINUE | `0x003C` | Yes | Yes | SST string continuation supported |
| EXTSST | `0x00FF` | Skip | No | Optional SST acceleration record |

## Formula tokens

The reader decodes common arithmetic, comparison, reference, range, literal, and built-in function tokens. Unknown token sequences do not prevent cached-result reads.

The writer compiles the documented formula subset in the main README. Unsupported functions and syntax raise `UnsupportedXlsFeatureException` instead of emitting an invalid workbook.
